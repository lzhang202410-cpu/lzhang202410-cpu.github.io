计算物理

发表于2026-06-01|更新于2026-09-30|计算物理核心技能

本篇为计算物理全流程基本功与实战总结，系统梳理了从基础开发环境、代码工程到超算集群与第一性原理材料计算的核心技能栈：

  • Hexo 搭建个人博客教程：从 Node.js 运行引擎、Git 身份配置到 Hexo 站点初始化、常用指令速查及 GitHub Pages 一键自动化部署；
  • Markdown 语法规范与排版指南：系统整理学术笔记排版必备语法，涵盖标题样式、列表、表格与 LaTeX 公式；
  • Linux Shell 常用命令与开发环境：包含 Python/Conda 虚拟环境、目录导航、打包解压、环境变量与 alias、流重定向及 Vim 全指南；
  • SSH 连接服务器与超算作业管理：解析 SSH 服务配置、Linux 三大数据流重定向、超算 Slurm 调度系统（sbatch/squeue/scancel）及后台实时监控；
  • VASP 第一性原理能带计算工作流：详述输入输出文件架构、收敛性判据、Si 能带六步法、HSE06 杂化泛函进阶与 STOPCAR 安全终止机制；
  • 计算物理科学计算核心代码库：汇集 MATLAB 数值积分/ODE相轨迹/插值与 Python 欧拉法刚性方程求解核心代码。
