六、 Vim 编辑器极速上手指南

  • 普通模式（Normal Mode）：光标移动、复制、剪切、撤销。按 Esc 随时返回此模式。
  • 插入模式（Insert Mode）：按 i（当前位置插入）、a（光标后插入）、o（下方另起一行）进入编辑。
  • 高频按键：
    • h / j / k / l：左、下、上、右移动；
    • w / b：按单词向前 / 向后跳转；
    • 0 / $：跳转至行首 / 行尾；
    • gg / G：跳转至全文首行 / 末行；
    • dd：删除（剪切）当前行；
    • yy：复制当前整行；
    • p：在光标后粘贴；
    • u：撤销上一步操作；
    • Ctrl + r：重做撤销的操作。
  • 底线命令模式（Command-Line Mode）：
    • :w：保存文件；
    • :wq：保存并退出；
    • :q!：强制放弃修改退出；
    • :%s/old/new/g：全局查找并替换。
