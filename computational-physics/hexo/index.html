三、 Hexo 常用指令速查表

指令 简写 功能描述
hexo clean hexo c 清理缓存：删除静态网页文件（public 目录）与缓存（db.json）。更换主题或修改配置后必做。
hexo generate hexo g 生成静态文件：将 Markdown 源码编译渲染为 HTML 静态页面。
hexo server hexo s 本地调试：启动本地服务器（默认端口 4000）进行实时修改效果预览。
hexo deploy hexo d 远端部署：根据 _config.yml 配置，将静态站点一键推送到 GitHub Pages。
hexo new "标题" hexo n 新建文章：在 source/_posts 目录下创建带有默认 Front-matter 头部的文章。
hexo new page "名" 无 新建独立页面：如生成自定义的 about 或 categories 单页。
