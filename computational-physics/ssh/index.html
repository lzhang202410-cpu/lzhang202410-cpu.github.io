二、 Linux 三大标准数据流机制

Linux 操作系统为每个进程默认打开三个标准文件描述符：

  • 0：标准输入（stdin），对应键盘或管道输入数据流；
  • 1：标准输出（stdout），程序常规正常打印信息；
  • 2：标准错误（stderr），程序报错、警告与异常跟踪堆栈。

三、 超算 Slurm 集群作业调度系统

绝大多数现代超算中心均采用 Slurm 负载均衡调度器，其核心作业管理指令如下：

命令 完整英文含义 常用场景与说明
sbatch run.bash Submit Batch Job 将写好的作业脚本提交至计算队列排队执行
squeue Show Queue 查看集群当前所有排队（PD）与正在运行（R）的作业
squeue -u $USER Show User Jobs 仅查看当前用户名下的作业状态，过滤他人任务
scancel <job_id> Cancel Job 终止并取消指定的作业任务编号
